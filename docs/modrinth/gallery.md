Files under `gallery/`, in the order they appear on the Modrinth page; the first is the featured
image. Captions go into Modrinth's gallery description field. **Not yet captured** — this is the
shot list for whoever takes them in the alpha client (`just client`, Fabric 26.2); `check` will
report the five files below as missing until they exist on disk.

| # | File | Caption |
|---|---|---|

| 2 | `02-subtitle.png` | Subtitles on: the same reaction with its vanilla subtitle showing. |

| 4 | `04-config-file.png` | `config/villager_voices.json` — cooldowns, the action bar toggle, and hearing range, all editable. |

Retake after any display-format or config change; each shot should be taken with default config
(`config/villager_voices.json` deleted, so the shipped defaults regenerate) unless the caption says
otherwise.
